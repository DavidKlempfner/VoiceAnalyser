## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Choose the voice analyser or the celebrity mimic challenge from the home screen. The challenge compares your recording with the selected clip locally using MFCCs, pitch and rhythm; scores are approximate and are not an assessment of identity or accent. Microphone access requires permission and a secure context (HTTPS or localhost).

Celebrity audio and portrait files are served from `public/`. The challenge expects matching `.mp3` and `.jpg` files for each slug in `src/data/celebrities.ts`. Portraits display a fallback when a file is missing.
